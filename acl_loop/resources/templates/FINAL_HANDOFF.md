# Final Handoff

This project-level file is populated only after evidence-backed acceptance.

Required closeout fields:

1. Final conclusion (`DONE`, `DONE_WITH_AUTOMATION_SETUP_REQUIRED`, or `BLOCKED`).
2. Goal scope and explicit exclusions.
3. Final task state and acceptance results.
4. Files changed.
5. Verification commands, outputs, exit codes, and evidence paths.
6. External source URLs and retrieval dates.
7. Git status before and after.
8. Scheduler status and concrete task IDs, or the exact setup-required reason.
9. Known limitations.
10. Pause, resume, uninstall, and rollback procedures.
11. The next goal-level instruction.

Do not use this template to claim that the containing business product is complete when only loop installation was accepted.
