# Automation Prompt Asset

The authoritative, copy-ready prompts are stored in:

```text
<runtime>/config/schedule-policy.yaml
```

Use these exact task names:

- `Autonomous Project Continuation`
- `Daily Autonomous Project Audit`

Use timezone `Australia/Sydney`. Do not manually maintain a second prompt copy here; this asset intentionally points to the centralized policy so cadence and safety instructions cannot drift.
